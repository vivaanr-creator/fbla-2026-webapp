# County Visitor Guide Starter

A small Flask scaffold for a county visitors website. Replace `[County Name]`, the placeholder copy, and the scenic image URLs with local destination content.

Pages:

- `/` - visitor homepage
- `/explore` - destination placeholder page
- `/experience` - activities and events placeholder page

## Run locally

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser. Flask debug mode is enabled for local development.
